여기서 확인해 주세요.

다운로드했는데 앱이 어디에 있나요?

휴대폰의 ‘내 파일’ 또는 ‘파일’ 앱에서 다운로드 폴더를 열어주세요. paperbook-0.6.43.apk를 누르면 설치 화면으로 이어집니다. 웹페이지는 다운로드 완료 여부를 확인할 수 없어요.

‘이 출처의 앱을 설치할 수 없음’이 나와요.

직접 받은 APK를 처음 설치할 때 Android가 출처 확인을 요청할 수 있어요. 파일을 받은 출처가 github.com/svalu/paperbook-releases인지 확인한 뒤, Android가 보여주는 해당 브라우저 또는 파일 앱의 설치 허용 안내를 따라주세요. 기기 보안 설정이나 회사 관리 정책으로 차단됐다면 그 안내를 확인해 주세요. 차단 사유가 표시되면 해당 안내를 확인해 주세요.

업데이트하면 내 책장과 기록이 사라지나요?

기존 앱을 삭제하지 않고 업데이트 설치하면 책장·독서 기록·메모를 유지할 수 있어요. 앱 삭제나 앱 데이터 초기화는 하지 마세요. ‘앱이 설치되지 않았습니다’ 같은 오류가 나면 삭제부터 하지 말고, 설치한 버전과 배포 출처를 먼저 확인해 주세요.

앱 안에서도 업데이트를 확인할 수 있나요?

직접 설치판 0.6.41부터 설정 → 업데이트 확인 → 업데이트 → Android 설치 확인로 진행해요. 홈페이지에 접속할 필요 없이 받을 수 있고, 마지막 설치 확인은 Android에서 해주세요. 이전 버전은 이번 설치 파일을 한 번 받아 업데이트해 주세요.

어떤 기기에 설치할 수 있나요?

Android는 APK, Windows 64비트 PC는 EXE 설치 파일을 받아주세요. 아이폰과 macOS 버전은 제공하지 않아요.

책 파일도 함께 제공하나요?

넘김은 직접 가진 파일을 여는 뷰어예요. 직접 만든 테스트용 샘플을 제공하며, 상용 만화나 유료 콘텐츠는 포함하지 않아요. 이용 권한이 있는 ZIP·CBZ·PDF 파일을 준비해 주세요.
